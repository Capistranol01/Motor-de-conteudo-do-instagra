# Prompt único por carrossel (colar de uma vez)

Mesmo conteúdo do [PROMPTS.md](/mnt/project-files/carrosseis/hotel-3-carrosseis-prompts/PROMPTS.md), mas cada carrossel virou **um bloco só**: estilo + todos os slides.

## Como usar

1. Chat novo no ChatGPT, **anexe as fotos reais na mesma mensagem** (na ordem indicada no topo de cada prompt) e cole o bloco inteiro.
2. O ChatGPT gera uma imagem por vez mesmo com tudo junto. Se ele parar no meio, responda só **"continua"** que ele segue do slide onde parou, sem você colar nada de novo.
3. Se um slide sair com texto errado: "Refaz o slide X igual, só corrigindo o texto para: ...".
4. O logo vai depois, no Canva (o prompt deixa o canto livre).
